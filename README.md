# Waste Pickup Scheduler

A responsive web application built with **HTML, CSS, and JavaScript** that enables users to schedule waste pickups, receive pickup reminders, and submit feedback to improve waste management services in Nigeria.

## Overview

The Waste Pickup Scheduler helps users book waste collection services quickly and efficiently. It provides a simple interface for scheduling pickups, viewing scheduled requests, receiving reminders, and submitting feedback. The application stores data locally using the browser's Local Storage, making it lightweight and easy to use without a backend server.

## Problem Statement

In many Nigerian communities, waste collection pickups are often unreliable, leading to delayed waste disposal, environmental pollution, and inconvenience for residents. This project provides a simple digital solution that enables users to schedule waste pickups, manage pickup requests, and provide feedback, helping to improve the efficiency of waste collection services.

## Project Objectives

* Provide a simple platform for scheduling waste pickups.
* Improve the reliability of waste collection services.
* Allow users to submit feedback on waste pickup services.
* Demonstrate practical web development skills using HTML, CSS, and JavaScript.

## Features

* 📅 Schedule waste pickups
* 📋 View scheduled pickups
* 📊 Dashboard with pickup statistics
* 🔍 Search scheduled pickups
* ⭐ Customer feedback and ratings
* 💾 Local Storage support
* 📱 Responsive design for desktop and mobile devices

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Local Storage
* GitHub Pages (Deployment)
