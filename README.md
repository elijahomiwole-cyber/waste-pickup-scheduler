# Waste Pickup Scheduler

## Overview
Waste Pickup Scheduler is a responsive web application designed to help users schedule waste pickups, receive reminders, and provide feedback on waste collection services. The application aims to improve the reliability and efficiency of waste management.

## Features
- Schedule waste pickups
- View scheduled pickups
- Pickup reminders
- Submit customer feedback
- Data stored using Local Storage
- Responsive design for desktop and mobile devices

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage

## How to Run
1. Clone the repository.
2. Open `index.html` in your web browser.
