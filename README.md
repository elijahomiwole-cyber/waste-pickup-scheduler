# Waste Pickup Scheduler

A responsive web application built with HTML, CSS, and JavaScript that enables users to schedule waste pickups, receive pickup reminders, and submit feedback to improve waste management services.

## Overview

The Waste Pickup Scheduler helps users book waste collection services quickly and efficiently. It provides a simple interface for scheduling pickups, viewing scheduled requests, receiving reminders, and submitting feedback. The application stores data locally using the browser's Local Storage, making it lightweight and easy to use without a backend server.

## Features

- 📅 Schedule waste pickups
- 📋 View all scheduled pickups
- 📊 Dashboard with pickup statistics
- 🔍 Search scheduled pickups
- 🎯 Filter pickups by status
- ✏️ Edit scheduled pickups
- 🗑️ Delete scheduled pickups
- ✅ Mark pickups as completed
- ⏰ Pickup reminders for today's schedules
- ⭐ Customer feedback and ratings
- 💾 Local Storage support
- 📱 Responsive design for desktop and mobile devices
