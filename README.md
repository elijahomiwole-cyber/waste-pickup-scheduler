# Waste Pickup Scheduler

A responsive web application built with **HTML5, CSS3, and JavaScript** to help users schedule waste pickups, receive pickup reminders, and submit feedback. The project addresses the challenge of unreliable waste collection services in many Nigerian communities by providing a simple and user-friendly scheduling platform.

---

## Overview

The **Waste Pickup Scheduler** enables users to book waste collection services quickly and efficiently. Users can schedule pickups, view scheduled requests, search for pickups, monitor basic pickup statistics, and submit customer feedback. The application uses the browser's **Local Storage**, allowing data to persist without requiring a backend server.

---

## Problem Statement

Waste collection pickups are often unreliable in many Nigerian communities, resulting in delayed waste disposal, environmental pollution, and inconvenience for residents. This project provides a simple digital solution that improves waste collection by allowing users to schedule pickups and communicate service feedback.
